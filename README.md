# Valentine Heart Catch Game

A tiny browser game for Valentine's Day.

## How to play

- Click **Start Game**.
- Catch as many 💖 hearts as you can in 30 seconds.
- Avoid 💔 broken hearts (they lower your score).
- Reach **20+ points** to win.

## Run locally

You can open `index.html` directly in your browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
